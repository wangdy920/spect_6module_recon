# SPECT_recon 2026-09-13 CUDA角度子集RC

本包支持CSRB角度子集OSEM和BSREM，以及BSREM每子更新的RDP/TV。CSRQ双系统矩阵联合重建继续作为实验路径，必须显式选择N1。矩阵与采集数据不随包分发。

- `-it A:B`明确为A次完整迭代、B个子集；`-save-every N`独立控制保存，默认0只保存末次。阶段参数仍为`-subsets 子集数:迭代次数,...`，搭配不带冒号的`-it A`。
- 默认OSEM及BSREM均为`50:10`，按compact角度交错划分，同一对称轨道不拆开。子集数必须整除compact角度数。N10用于已验证系统上的快速常规重建，严格收敛要求可显式递减到N1；没有跨系统全局最优保证。
- 子集灵敏度为零但全数据灵敏度为正时，MLEM保留当前体素，防止子更新误清零。POSEM已从当前工作区移除，旧像素划分参数明确报错。
- 修复发布配置使正则化可用：关闭旧的全局section覆盖，采用命令行 > 算法配置 > 全局配置。`-opti bsrem`默认RDP，`-opti bsrem -reg tv`选择TV。β默认0.3仅是已有参数起点，未宣称适合所有对象的最优平滑强度。
- 每个BSREM子更新使用当前图像的正则梯度；数据项乘子集数，β保持原值，步长按完整迭代衰减。默认κ权重保留，因此不要把其结果解读为无空间加权的固定β目标。
- 默认输出primary与Butterworth副本，额外Gaussian关闭。算法比较使用primary。

构建：独立VS18 2026 / CUDA toolkit 13.2.51，fatbin包含sm_86、sm_89、sm_120；运行需要受支持CUDA设备和驱动，不提供纯CPU回退。旧发布包与冻结EXE未覆盖。当前来源为`00d5edb`上的未提交工作区，精确EXE/配置/DLL及源码补丁哈希随验证记录保存。

验证详情见`docs/release_validation.json`；实验解释与原始命令见项目报告`reports/2026-09-13-subset-release.md`。300项测试通过，4项外部数据或opt-in测试跳过；支持真实数据的范围以随包验证记录为准。
