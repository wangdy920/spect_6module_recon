| **重叠区几何处理**<br>(Overlap Handling) | **全局灵敏度累加 (Global Sensitivity Accumulation)**<br>利用重叠区体素被多次采样的特性，将各床位灵敏度在全局空间进行代数和（Accumulate），实现平滑过渡和信噪比提升（$\sqrt{2}$倍）。 | **已实现 (Implemented)**<br>v1.3.0 引入 `-bedOverlap`。<br>支持物理重叠的几何映射和灵敏度自动累加（Weighted Fusion）。<br>系统矩阵通过预计算偏移（`bedOffsetVoxels`）自动处理重叠区索引。 | **已完成**<br>通过设置 `-bedOverlap <pixels>` 即可开启。<br>支持单个固定重叠量或逐床位指定。<br>后续可考虑添加 `-cropZ` 进行自动边缘裁剪。 |
| **CT衰减校正 (CTAC)**<br>(Attenuation Correction) | **动态射线追踪 (On-the-fly Ray Tracing)**<br>使用单床位系统矩阵，但在投影计算中动态采样**全局$\mu$-map**来计算衰减因子。允许在低内存（Shared System Matrix）下进行全场AC。 | **已实现（一阶平行射线 line-integral）**<br>`-ctac` 默认使用角度相关的平行射线积分 `exp(-∫mu ds)`（`-ctacModel line-integral`，含体素间距与旋转方向 `-ctacRotSign`），逐床位、逐角度预计算 `bedAttenFactors` 并在 OSEM/BSREM 循环中应用；支持与 `-mapCSR on` 同时使用。<br>限制：射线按平行几何近似（Z 向水平），未沿针孔系统矩阵的真实汇聚射线积分。<br>旧 per-voxel `exp(-mu)` 近似保留为 `-ctacModel per-voxel`（仅供对比，非定量）。 | **验证**<br>需在物理 phantom（均匀圆柱 + 偏心热源）上验证旋转方向约定与定量精度；后续如需更高精度可沿系统矩阵射线做 Siddon 积分。 |
| **系统矩阵复用**<br>(System Matrix Reuse) | **索引偏移 (Index Offsetting)**<br>通过内存指针偏移复用单床位矩阵。 | **已实现 (Implemented)**<br>v1.3.0 引入了基于 `bedCount` 的虚拟堆叠和 SIMD 偏移，完全符合标准。 | **保持现状**<br>当前的隐式扩展逻辑已坚实，无需重大改动。 |
| **正则化连续性**<br>(Regularization Continuity) | **全局约束 (Global Constraint)**<br>正则化（如TV、Bowsher）应作用于整个融合后的体积，确保床位交界处平滑。 | **已实现 (Implemented)**<br>所有正则化器（`Regularizers.cpp`）均在 `image` 全局向量上运行，天然跨越了（当前的）虚拟边界。 | **验证重叠区行为**<br>若实施了“重叠区混合”改进，需确保正则化梯度在重叠区（灵敏度较高）的权重计算正确（Beta应相对于灵敏度进行归一化适配）。 |
| **散射校正**<br>(Scatter Correction) | **跨床位散射建模 (Cross-bed Scatter)**<br>利用全局体数据估算散射，并将其作为背景项加回。 | **外部输入支持 (External Input)**<br>支持 `-bProjList` 加载外部计算好的散射/背景正弦图。 | **文档增强**<br>明确说明需要外部 Scatter Solver（如 CASToR 或蒙特卡洛模拟）来生成能够处理跨床位效应的散射项。 |
| **采集模式**<br>(Acquisition Mode) | **连续床位运动 (Continuous Bed Motion)**<br>现代系统趋势，灵敏度沿 Z 轴均匀。 | **步进模式 (Step-and-Shoot)**<br>主要支持离散的床位步进。 | **长期规划**<br>未来可探索基于连续时间戳的事件列表重放（List-mode Replay），支持任意连续位置的重建。 |
